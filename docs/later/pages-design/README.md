# Shelved: the pages-and-widgets design (13 Oct 2026)

The first design: pourOver as its own app, with its own store, one page per topic, a widget kit (checklist, table, bar chart), view specs and themes. Shelved on 14 Oct 2026 when stir 3 turned pourOver into a translator over Vikunja ([../../ideas/pourover.md](../../ideas/pourover.md)).

Kept because two parts are still useful later:
- `design-spec.md`: theme tokens, copy and accessibility rules, if pourOver ever gets its own pages
- `architecture.md`: the view-spec renderer and widget kit

Nothing here is v1 scope. `README-original.md` and `plan-original.md` are the docs as they were before the rewrite.
